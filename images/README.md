# 📷 Danh sách ảnh cần đặt vào thư mục này

Đặt ảnh **đúng tên file** bên dưới (chữ thường, đúng đuôi `.jpg` / `.png`).
Khung nào chưa có ảnh sẽ hiện ô sọc kèm tên file cần thêm. Thêm đúng ảnh là ô đó tự biến mất.

> Mẹo: nén ảnh trước khi đưa lên (dùng https://squoosh.app hoặc https://tinypng.com).
> Mỗi ảnh nên **dưới 500KB** (riêng ảnh bìa dưới 800KB) để thiệp mở nhanh trên điện thoại.
