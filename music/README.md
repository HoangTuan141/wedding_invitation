# 🎵 Nhạc nền

Đặt file nhạc vào đây với tên **`song.mp3`** (nên dưới 5MB, có thể cắt bớt đoạn intro).
Nhạc sẽ tự phát khi khách bấm "Mở thiệp". Khách có thể bật/tắt bằng nút đĩa nhạc ở góc phải dưới.

Muốn dùng tên file khác thì sửa dòng `music:` trong `js/config.js`.
Nếu không muốn có nhạc, đặt `music: ''`.
